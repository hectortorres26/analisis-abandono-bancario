# Abandono bancario: diagnóstico por segmentos

Análisis exploratorio de 10.000 clientes bancarios con Python, pandas, NumPy y Matplotlib. Cuantifica una tasa de abandono del 20,37 % y compara segmentos de edad, país, actividad y productos mediante intervalos de Wilson. Presenta indicadores y visualizaciones agregadas para orientar hipótesis de retención, con validaciones de calidad y un flujo reproducible.

**Repositorio:** [analisis-abandono-bancario](https://github.com/hectortorres26/analisis-abandono-bancario)

**Alcance:** Identificar segmentos con mayor proporción de abandono para orientar hipótesis de retención. El análisis describe asociaciones en una muestra educativa de clientes; no estima el efecto causal de una campaña ni construye un sistema de decisiones individuales.
